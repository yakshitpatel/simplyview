Actually view your Drive files.

Drive shows your .md, .json, .py, .html as plain source. SimplyView renders them properly — without leaving the tab.

Add to Chrome — free Source on GitHub →

What it renders

HTML · Markdown (GFM, syntax-highlighted code blocks, task lists) · JSON (collapsible tree, search, copy formatted) · 30+ code languages — JS, TS, Python, Ruby, Go, Rust, Java, Kotlin, Swift, C, C++, C#, PHP, CSS, YAML, TOML, SQL, Shell, XML, Diff, Lua, R, Scala, Perl, Dart, GraphQL, Protobuf, Dockerfile, …

What's different

Modal preview support

Works in the standalone file view and in Drive's folder modal preview — not just one or the other.

No data leaves your browser

No servers, no analytics, no tracking. The extension fetches files only from drive.google.com using your existing session.

Dark mode

Auto-matches your system theme. Renderer, overlay chrome, and syntax highlighting all swap together.

Keyboard shortcut

⌘⇧Y on Mac, Ctrl⇧Y on Windows/Linux. Skip the mouse.

Privacy

SimplyView has no servers and collects no data. The full source code is open at github.com/yakshitpatel/simplyview. See the full privacy policy for the Chrome Web Store Limited Use disclosure.
